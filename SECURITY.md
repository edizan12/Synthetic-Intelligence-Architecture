# Security Policy

## Supported Versions

The following versions of **SI Architecture** are currently supported with security updates and memory-leak patches:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of tensor manipulation and API token management very seriously. 

If you discover a security vulnerability, Hugging Face token leakage, or critical VRAM overflow risks, please do not open a public issue. 
Instead, report it directly by contacting the project maintainer via GitHub profile options.
